# NEREID Ocean Mapping Simulator

A real-time 3D ocean floor mapping simulation demonstrating the capabilities of the NEREID vehicle fleet and its Cerulean sonar systems. Players/viewers observe and direct autonomous and simulated-teleoperated unmanned vehicles scanning a procedurally generated seafloor, watching a bathymetric map build in real time.

Web Demo: [NERIED Ocean Mapping on itch.io](https://ecodevguy.itch.io/nereid-ocean-mapping?secret=v4SK5AhUwkuGSHZv0pOSWdv79lw)

## Requirements

[Godot 4.6](https://godotengine.org/download/archive/4.6-stable/) 

## Controls

### Camera

b : set camera to bird's eye view

v : set camera to chase active vehicle

### Simulation Speed

1 : normal speed

2 : 2x speed

3 : 4x speed
